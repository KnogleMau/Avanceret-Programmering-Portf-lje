Quicksort — trin for trin

Pivot er altid det sidste element i det aktive område (som i din Java-kode).

Pivot
j (tjekkes nu)
≤ pivot (small zone)
Aktiv, ikke klassificeret endnu
Låst på endelig plads
Venter på senere rekursion
Skridt 0
Klik "Næste" for at starte.

Pseudokode

quickSort(arr, low, high):
  if low < high:
    pivotIdx = partition(arr, low, high)
    quickSort(arr, low, pivotIdx - 1)
    quickSort(arr, pivotIdx + 1, high)

partition(arr, low, high):
  pivotValue = arr[high]
  i = low - 1
  for j = low ... high - 1:
    if arr[j] <= pivotValue:
      i++; swap(arr[i], arr[j])
  swap(arr[i+1], arr[high])
  return i + 1
